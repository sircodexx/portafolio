# Portafolio de Miguel Ángel Yamunaqué Villegas

React + Vite + Tailwind CSS 4 + Lucide React.

## Desarrollo (PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
```

## Compilación

```powershell
npm.cmd run build
npm.cmd run preview
```

## Personalización

Edita `src/App.jsx`: el objeto `contact`, los repositorios de `projects` y la lista `experience`.
Los enlaces vacíos se muestran desactivados. Los proyectos y empleos son ejemplos.
Los estilos globales están en `src/index.css`.
