# Capturas de proyectos

Una imagen por proyecto (`.jpg`, `.png` o `.webp`, idealmente 1280×800, proporción 16:10).
El nombre del archivo debe coincidir con el campo `image` de `src/content.js`:

- `nistrack.webp`
- `termometro.webp`
- `keptai.webp`
- `agrimonitor.webp`

Si falta una imagen, la tarjeta muestra una ilustración de código.
